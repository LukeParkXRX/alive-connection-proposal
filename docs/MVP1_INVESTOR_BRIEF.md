# ALIVE Connection MVP 1단계
## 투자자 기술 비전 브리프

---

## Executive Summary

**ALIVE Connection**은 BLE(Bluetooth Low Energy) 기술을 활용하여 오프라인 만남의 순간을 디지털 자산으로 전환하는 **관계 지능 플랫폼**입니다. MVP 1단계에서는 "제로 입력 연락처 교환"이라는 핵심 가치를 구현하여, 사용자가 타이핑 없이 스마트폰을 가까이 대는 것만으로 상대방의 연락처를 획득하고 만남의 맥락(시간, 장소)을 자동으로 기록하는 경험을 제공합니다.

---

## 1. 왜 이 문제를 해결해야 하는가

### 현재 네트워킹의 한계

비즈니스 네트워킹 현장에서 우리는 여전히 **1990년대의 방식**으로 인맥을 관리합니다. 컨퍼런스에서 만난 50명의 사람들, 그 중 실제로 연락처를 저장한 사람은 몇 명일까요? 종이 명함을 받아도 책상 서랍에 쌓이고, 수동으로 연락처를 입력하다 지쳐 포기합니다.

더 큰 문제는 **맥락의 상실**입니다. "이 사람을 어디서 만났지?", "무슨 이야기를 나눴더라?" 3개월 후 연락처 목록을 보면 이름만 있을 뿐, 그 만남의 가치는 사라져 있습니다.

### ALIVE가 해결하는 문제

ALIVE Connection은 이 문제를 근본적으로 해결합니다. **만남의 순간, 모든 것이 자동으로 기록됩니다.** 누구를, 언제, 어디서 만났는지. 사용자는 아무것도 입력하지 않습니다. 단지 스마트폰을 가까이 대기만 하면 됩니다.

---

## 2. MVP 1단계의 기술적 핵심

### 2.1 BLE 기반 즉시 연결 (Zero-Input Exchange)

MVP 1단계의 핵심은 **BLE(Bluetooth Low Energy) 기술**을 활용한 즉시 연락처 교환입니다.

두 사용자의 스마트폰이 약 30cm 이내로 근접하면, BLE 신호를 통해 프로필 정보가 **양방향으로 동시에** 교환됩니다. ALIVE만의 **Fast Path 프로토콜**은 Manufacturer Data에 userId를 직접 인코딩하여 GATT 연결 없이 약 100밀리초 만에 교환을 완료합니다.

기존 QR코드 기반 솔루션이나 Apple의 NameDrop과의 차별점은 **자동성과 맥락**입니다. QR코드는 한 사람이 보여주고 한 사람이 스캔하는 일방향 프로세스이며, NameDrop은 연락처만 전달할 뿐 만남의 맥락을 기록하지 않습니다. ALIVE의 BLE 핸드셰이크는 두 사람이 동시에 상대방의 정보를 받으며, 시간과 장소가 자동으로 태깅됩니다.

### 2.2 커스텀 네이티브 BLE 모듈

Android(Kotlin)와 iOS(Swift) 각각에 대해 **커스텀 BLE Peripheral 네이티브 모듈**을 자체 개발했습니다. 이를 통해:
- GATT 서버와 BLE 광고를 단일 모듈에서 완벽 제어
- Manufacturer Data에 커스텀 바이너리 프로토콜 인코딩
- Expo Config Plugin으로 빌드 자동화

이것은 단순한 라이브러리 조합이 아닌, **하드웨어 레벨의 최적화**입니다.

### 2.3 컨텍스트 자동 캡처 (Contextual Memory)

연락처 교환이 발생하는 순간, 시스템은 자동으로 **만남의 컨텍스트**를 기록합니다.

GPS 좌표를 획득하고, 역지오코딩(Reverse Geocoding)을 통해 "스타벅스 강남역점"과 같은 인간이 이해할 수 있는 장소명으로 변환합니다. 타임스탬프와 함께 저장된 이 정보는 나중에 "강남에서 만난 사람", "CES에서 만난 사람"과 같은 맥락 기반 검색을 가능하게 합니다.

이것이 ALIVE를 단순한 연락처 앱이 아닌 **관계 기억 시스템**으로 만드는 핵심입니다.

### 2.4 듀얼 모드 아이덴티티 (Contextual Identity)

ALIVE는 **Business 모드**와 **Casual 모드**를 제공합니다. 비즈니스 미팅에서는 이메일과 LinkedIn을, 캐주얼한 모임에서는 Instagram과 WhatsApp을 공유합니다. 홈 화면에서 한 번의 탭으로 모드를 전환할 수 있으며, BLE 교환 시 현재 활성화된 모드의 프로필만 전송됩니다.

### 2.5 시간 기반 관계 타임라인 (Temporal Relationship View)

수집된 연결은 **시간순 타임라인**으로 정렬됩니다. "오늘", "어제", "이번 주"와 같은 자연어 섹션으로 그룹핑되어, 사용자는 자신의 네트워킹 활동을 시간의 흐름 속에서 파악할 수 있습니다.

### 2.6 지식그래프 통합 (ALIVE Engine)

모든 만남 데이터는 **ALIVE Engine 지식그래프**에 자동으로 축적됩니다. Neo4j 기반 그래프 데이터베이스에 Person 노드와 MET_AT 관계가 생성되며, 이는 향후 AI 기반 관계 인사이트의 기반이 됩니다. 오프라인 환경에서도 AsyncStorage 큐에 연산을 저장하고, 네트워크 복구 시 자동 동기화합니다.

## 3. 기술 스택과 선택의 이유

### 3.1 React Native + Expo (Bare Workflow)

크로스 플랫폼 개발을 위해 React Native와 Expo를 선택했습니다. 다만 BLE Peripheral 기능을 위해 **Bare Workflow**를 채택하여 커스텀 네이티브 모듈(Kotlin/Swift)을 직접 통합했습니다. Expo Config Plugin으로 빌드 자동화를 유지하면서도 하드웨어 레벨 제어가 가능합니다.

### 3.2 Supabase (PostgreSQL + Realtime)

백엔드로 Supabase를 선택한 이유:
- **PostgreSQL의 안정성**: 사용자-연결-장소 간의 복잡한 관계를 표현
- **실시간 동기화**: Realtime 구독으로 즉시 메시징, 알림 기능 구현
- **인증 통합**: OAuth, 세션 관리, RLS를 단일 플랫폼에서 처리

### 3.3 ALIVE Engine (FastAPI + Neo4j)

관계 데이터를 **지식그래프**로 모델링합니다. 8개 도메인, 21개 노드 타입, 37개 관계 타입의 온톨로지를 통해 "A와 B를 모두 아는 사람은?", "가장 자주 만나는 산업군은?"과 같은 그래프 쿼리를 가능하게 합니다.

## 4. MVP 1단계가 검증한 것

### 4.1 핵심 가설 — 검증 완료

**"사람들은 네트워킹 현장에서 더 빠르고 자동화된 연락처 교환 방식을 원하며, 만남의 맥락이 함께 기록되는 것에 가치를 느낀다."**

### 4.2 기술 검증 결과

- **BLE Fast Path**: Manufacturer Data를 통한 ~100ms 교환 성공
- **크로스 플랫폼**: Android(Kotlin) ↔ iOS(Swift) BLE Peripheral 안정 동작
- **GPS 안정성**: 3초 타임아웃 + 최근 위치 폴백으로 실내/실외 모두 대응
- **오프라인 내성**: AsyncStorage 큐 기반 ALIVE Engine 연산 지연 동기화

## 5. MVP 1단계 이후의 로드맵

### MVP 2단계: 관계 시각화 (3월)
수집된 연결 데이터를 기반으로 **나를 중심으로 한 인맥 네트워크 그래프**를 시각화합니다. 관계의 강도에 따라 엣지의 두께가 달라지고, 회사/산업/장소별로 클러스터링된 인맥 지도를 제공합니다.

### MVP 3단계: 관계 지능 (4월~)
AI가 관계 패턴을 분석하여 인사이트를 제공합니다. "3개월간 연락하지 않은 중요 연결", "소개해드릴 만한 공통점이 있는 두 사람" 등의 지능형 기능을 통해 ALIVE는 **개인 관계 비서**로 진화합니다.

## 6. 경쟁 우위

| 기존 솔루션 | 한계 | ALIVE의 접근 |
|-------------|------|--------------|
| 종이 명함 | 수동 입력, 맥락 상실, 검색 불가 | 제로 입력, 자동 맥락 기록 |
| QR코드 명함앱 | 일방향 교환, 추가 앱 설치 필요 | BLE 양방향 동시 교환, 자동 감지 |
| LinkedIn | 온라인 전용, 오프라인 만남 기록 불가 | BLE 근접 + 온라인 통합 |
| AirDrop/NameDrop | 연락처만 전달, 관계 맥락 없음 | 시간/장소/메모 자동 기록, 지식그래프 |
| CRM | 수동 입력 부담, 개인용 부적합 | 자동화된 개인 관계 관리 |

---

## 7. 결론

ALIVE Connection MVP 1단계는 **"만남을 기록하다"**라는 단순하지만 강력한 가치 제안을 기술적으로 구현했습니다.

BLE를 통한 즉시 양방향 연결, GPS를 통한 자동 맥락 캡처, 지식그래프 기반 관계 저장, 그리고 시간 기반 타임라인은 함께 작동하여 사용자에게 완전히 새로운 네트워킹 경험을 제공합니다. 사용자는 더 이상 연락처를 "관리"하지 않습니다. 그저 만나고, 기억하고, 연결됩니다.

이것이 ALIVE가 만들어가는 **관계 지능의 첫 번째 장**입니다.
